# Project 2 Storymap

This folder is a snapshot of a Storymap Preview — the finished narrative, maps, and sources. It is not the Spatial Intelligence editor and does not stay in sync with later edits.

## Open it

1. **On your computer:** in this folder run `npx serve` (or any static file server), then open the URL it prints. Double-clicking `index.html` may work; a local server is more reliable for maps.
2. **GitHub Pages:** upload this folder (or put it in `/docs`) and enable Pages.
3. **Cloudflare Pages:** upload the folder as a static project.

## Maps

Basemaps are free public tiles (© OpenStreetMap contributors © CARTO © Esri). There is no MapTiler or Mapbox key in this zip. You can later point `index.html` at your own tile service if you want.

## What is not included

Spatial Intelligence login, the editor, live data refresh, analysis jobs, or any project secrets.
